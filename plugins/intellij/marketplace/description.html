Explore Siglo workflows directly in IntelliJ IDEA. Siglo Workflows turns workflow source into an interactive graph so you can understand composition, inspect step settings, and navigate to definitions.

Visual workflow explorer

  • Follow sequential steps, parallel forks and joins, conditional branches, races, compensation paths, and fallbacks.
  • Switch between workflows in a file or compare them with the All Flows view.
  • Click a graph step to inspect its properties and open its source location.
  • Keep the graph in sync with the active editor and automatically refresh it as you type, or reload manually.

Step and workflow inspection

  • Inspect declared retries, timeouts, compensation, and source coordinates.
  • Explore input contracts from .spec(...) and .schema(...), including required fields, defaults, validators, transforms, and schemas.
  • Review workflow deadlines, schema versions, network policies, and monitor expressions.
  • Recognize core steps and supported HTTP, AI, notification, crypto, and durable wait patterns.
  • Deep-dive into ecosystem steps with optional offline telemetry recording imports and fail-closed secret redaction.

Static code diagnostics

  • Detect DAG cycles (SIGLO_STATIC_CYCLE) and duplicate step IDs (SIGLO_DUPLICATE_STEP_ID).
  • Flag missing compensations on side-effect sagas (SIGLO_MISSING_COMPENSATION).
  • Warn on unhandled error branches in durable workflows (SIGLO_UNHANDLED_ERROR_BRANCH).

Static analysis

The Node.js analyzer reads source using the TypeScript Compiler API without executing your application code. The graph describes declared structure and settings; it does not display live execution traces or runtime results. Dynamic expressions may remain unresolved.

Getting started

  1. Install Node.js 18 or newer and make the @siglo/ide-analysis analyzer available in your workspace, or configure SIGLO_ANALYZER_BIN with the path to its dist/bin.js file.
  2. Open a trusted project containing Siglo workflow source.
  3. Open a JavaScript or TypeScript file and choose Visualize Siglo Workflow from the editor context menu, or open View → Tool Windows → Siglo Workflows.
  4. Select a workflow or click a step to explore its settings and source.
  5. Optionally choose Import Siglo Telemetry Recording... to inspect recorded execution metrics offline.

Targets IntelliJ Platform 2024.1 and newer (build 241+). The interactive graph uses JCEF; when JCEF is unavailable, the plugin provides a native tree view.
